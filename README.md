# Lugdunum

Outil de diagnostic financier automatisé pour les PME françaises.

À partir du SIREN d'une entreprise, Lugdunum récupère ses comptes annuels publics,
calcule les soldes intermédiaires de gestion et les principaux ratios, attribue un
score de santé financière et produit un diagnostic commenté.

🚧 Projet en cours de construction.
